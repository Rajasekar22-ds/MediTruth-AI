📌 Project Description

MediTruth AI is an AI-based medical news verification system designed to identify fake, misleading, or unverified medical information from both text and images. The system uses Natural Language Processing (NLP) and Machine Learning (ML) techniques to analyze user-provided medical content and classify it as Real Medical News, Possibly True, or Fake / Unverified.
